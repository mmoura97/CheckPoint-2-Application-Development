# CheckPoint 2 - Catálogo de Atores e Atrizes

Projeto de um aplicativo web construído com HTML, CSS e JavaScript para exibir e filtrar um catálogo de atores e atrizes[cite: 1]. Desenvolvido como avaliação para a disciplina de Application Development (Prof. Rodrigo).

## 🚀 Funcionalidades

- **Renderização Dinâmica:** Exibição de todos os atores e atrizes provenientes do arquivo `dados.js` em um grid de cards[cite: 1]. Cada card contém a foto, nome, país e data de nascimento[cite: 1].
- **Busca em Tempo Real:** Campo de texto (`<input type="text">`) que filtra os cards pelo nome exatamente conforme o usuário digita[cite: 1].
- **Lógica de Filtro:** Implementação baseada no evento `oninput`, utilizando os métodos `filter()` e `includes()` do JavaScript[cite: 1].
- **Interface Responsiva:** Design moderno em "Dark Mode", utilizando CSS Grid e Media Queries para se adaptar perfeitamente a computadores, tablets e smartphones.
- **Animações (UI/UX):** Efeitos de transição suaves nos cards utilizando `:hover` e `transform`.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura e semântica.
- **CSS3:** Box Model, Grid Layout, Flexbox e estilização avançada.
- **JavaScript (ES6+):** Manipulação da DOM, Arrow Functions, Template Strings e iteração de Arrays (`forEach`, `filter`).

## ⚙️ Como executar o projeto

1. Clone este repositório em sua máquina.
2. Abra a pasta raiz do projeto no VS Code.
3. Certifique-se de ter a extensão **Live Server** instalada.
4. Clique com o botão direito no arquivo `index.html` e selecione **"Open with Live Server"**.
